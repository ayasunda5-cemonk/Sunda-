📲 Install Jadi APK

  1. Upload semua file ini ke GitHub (index.html, manifest.json, sw.js, offline.html, folder icons/)
  2. Deploy di Vercel dari repo GitHub itu
  3. Buka link Vercel di pwabuilder.com → Build → Android → Download APK / AAB
  4. Install APK-nya. Setelah dibuka sekali, aplikasi bisa dibuka offline tanpa internet.
